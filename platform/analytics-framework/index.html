Live Analytics

Analytics Computed from the Source

The SpiderRock Platform is powered by live market data taken from exchange feeds and normalized internally. The system computes options analytics in real-time — implied volatilities, Greeks, and volatility surfaces — driving both risk management systems and proprietary algorithmic routing techniques.

All live data and analytics are visible through SpiderRock's GUI Tools and accessible programmatically via SRSE or the MLink API, giving clients the flexibility to integrate SpiderRock analytics directly into their own workflows.

Framework Components

Four Layers of Intelligence

Enhanced Order Routing

Volatility surfaces and alpha probabilities feed directly into routing decisions. Real-time analytics update on every option tick, giving the routing engine a continuously fresh view of fair value for every instrument traded.

TCA Metrics

Transaction cost analysis provides post-trade insights on execution quality, slippage, and market impact. TCA data is generated from the same analytics used to make routing decisions, ensuring apples-to-apples comparisons.

Enhanced Risk Management

The analytics framework feeds risk models with current volatility estimates, surface prices, and Greeks. This tight integration between analytics and risk ensures that portfolio risk calculations reflect the most current market conditions.

Programmatic Access

Access all live analytics programmatically via SRSE (MySQL API) or MLink (REST/WebSocket). Client libraries are available in C++, C#, and other common languages, enabling full integration with proprietary systems.
