Our new Liberator API allows you to select data points by ticker or groups and by date and time ranges for direct use within your own applications. Our API comes with starter codes and notebooks for different languages as well as a Microsoft Excel plug-in.

Using the API reduces the need to download and store large datasets during your research process and allows you to focus your efforts on performing the analysis.  Through our Liberator API, you can access SpiderRock options, stock, and futures data within your own application using our cloud compute power and pre-optimized query access.
