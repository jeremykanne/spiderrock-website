Overview

Real-Time and Historical Data Delivery

Effective analytical workflows are a critical component of trade strategy development. SpiderRock data delivery solutions combine institutional quality market data and analytics with resource-efficient delivery mechanisms — covering market data feeds, live analytics, and historical data.

Market Data Feeds

Vendor of record, low latency raw/normalized US equities, options, and futures

Live Analytics

Greeks, implied volatilities, volatility surfaces, historical volatilities, risk factors, trade performance

Historical Analytics

Snapshots of live data/analytics: end-of-day, intraday, minute bar, previous day. Up to 10 years

Real-Time

Market Data Feed Delivery

SpiderRock provides raw and normalized low latency multicast feeds covering US equities, options, and futures markets. We are an exchange licensed redistributor of market data.

Low Latency Service

Exchange feed pre-processing using FPGA and kernel bypass technology with Arista switches and 10GB/40GB fiber connections for fast normalized data feeds.

Hosted Solution

Hosted within NY4/5 and CH2 data centers. Client software runs on SpiderRock-owned hardware or in client environments using SpiderRock-supplied C++/C# APIs.

Normalized OPRA Feed

A normalized version of the OPRA feed processed on a single thread of a single core. Typically 1/10th the size of raw OPRA — more manageable for firms needing real-time options data.

Proprietary

Live Analytics Delivery

Low-cost delivery of market data and options analytics without significant infrastructure investment. Analytics for volatility and surface modeling capable of supporting live trading operations.

Volatility and Greeks Feed

A reliable real-time feed for all US-listed options providing NBBO prices, bid/ask implied volatilities, SpiderRock surface volatilities, Greeks, and proprietary analytics.

Delivery Formats

Analytics distributed as multicast messages via C++/C# API or queried via MySQL API. Live, delayed, or query data through a robust, reliable technical infrastructure.

Historical

Historical Data Delivery Options

Cloud-Based File Delivery

Data tables organized by format type (closing marks, minute bars, surfaces, prints) and loaded into cloud storage overnight, partitioned by date. Daily subscription files and bulk historical downloads available.

Liberator API

On-demand historical data access by ticker, groups, date, and time ranges. Starter codes and notebooks in Python, R, C++, C#, JavaScript, and a Microsoft Excel plug-in. No need to download large datasets during research.

Data Portal

Browser-based access for customers to view, search, filter, and download historical data files within their subscription. No API integration required for simple file access.
